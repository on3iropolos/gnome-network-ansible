# Guidelines for AI Agents

This document provides a high-level overview of the guidelines and instructions for AI agents working with the Gnome Network Ansible repository. As an AI agent, you **MUST** adhere to these guidelines to ensure consistency, maintainability, and effective collaboration.

The detailed instructions are organized into separate files within the `.agent/instructions/` directory. It is your responsibility to read, understand, and follow all the instructions in these documents before making any changes.

## Core Instructions

-   [**General Instructions**](./.agent/instructions/general_instructions.md): Start here to understand the fundamental principles of working in this repository.
-   [**Agent Working Directory**](./.agent/instructions/working_directory.md): Learn about the designated working directory for agents and the requirements for logging and summarizing your work.
-   [**Documentation**](./.agent/instructions/documentation.md): Find out how to properly document your changes, including creating and updating `README.md` files.
-   [**Testing and Linting**](./.agent/instructions/testing_and_linting.md): Review the requirements for testing and linting your code to ensure it meets the project's quality standards.
-   [**Interaction**](./.agent/instructions/interaction.md): Understand the protocols for interacting with users and handling conflicting instructions.
-   [**Mermaid Diagram Guidelines**](./.agent/instructions/mermaid_diagram_guidelines.md): Learn how to create and maintain Mermaid diagrams to visually represent workflows and architectures.

Failure to follow these instructions may result in your changes being rejected. If you have any questions or are unsure about any of these guidelines, please ask for clarification.
