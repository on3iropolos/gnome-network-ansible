Thank you for installing {{ .Chart.Name }}.

Your release is named {{ .Release.Name }} and is running in namespace {{ .Release.Namespace }}.

To learn more about the release, try:

    helm status {{ .Release.Name }}
    helm get all {{ .Release.Name }}

To view the deployed resources:

    kubectl get all -l app.kubernetes.io/instance={{ .Release.Name }}

To access the application:

{{- if .Values.ingress.enabled }}
    Add to your /etc/hosts:
    127.0.0.1 {{ .Values.ingress.host }}

    Then access: http://{{ .Values.ingress.host }}
{{- else }}
    Port forward to access:
    kubectl port-forward svc/{{ include "sample-app.fullname" . }} 8080:80
{{- end }}

To uninstall the release:

    helm uninstall {{ .Release.Name }}
